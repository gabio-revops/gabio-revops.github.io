JavaScript Forms

Populate Hidden Form Field on Non-HubSpot Page

Captures UTM parameters, referrer, or any URL query string and populates a hidden field on an external form before submission to HubSpot. Essential for attribution tracking when you can't use HubSpot's native forms.
Use Case You're using Webflow, Wordpress, or custom forms but still want to track campaign attribution in HubSpot. This script reads URL parameters and injects them into hidden fields so they flow into HubSpot on form submit via the Forms API.
JavaScript 
// Get URL parameter by name
function getParam(name) {
  const params = new URLSearchParams(window.location.search);
  return params.get(name) || '';
}

// Populate hidden fields on page load
document.addEventListener('DOMContentLoaded', function() {
  // UTM parameters
  document.getElementById('utm_source').value = getParam('utm_source');
  document.getElementById('utm_medium').value = getParam('utm_medium');
  document.getElementById('utm_campaign').value = getParam('utm_campaign');
  
  // Referrer
  document.getElementById('referrer').value = document.referrer;
  
  // First page visited (store in sessionStorage)
  if (!sessionStorage.getItem('first_page')) {
    sessionStorage.setItem('first_page', window.location.href);
  }
  document.getElementById('first_page').value = sessionStorage.getItem('first_page');
});
Notes: Make sure your hidden input IDs match the field names expected by your HubSpot form. For HubSpot Forms API submissions, the field names must match your HubSpot property internal names exactly. Use sessionStorage for first-touch attribution so it persists across pages in the same session.
